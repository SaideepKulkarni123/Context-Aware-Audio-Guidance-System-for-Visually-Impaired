Context-Aware Audio Guidance System for Visually Impaired Users

Overview

A standalone assistive system designed to help visually impaired individuals navigate their surroundings using real-time object detection and audio feedback. The system runs on Raspberry Pi 4 and provides spoken alerts based on the detected objects and their estimated proximity.

Features

Real-time object detection using a camera.

Distance estimation based on detected objects.

Context-aware audio alerts based on object proximity.

Standalone operation using Raspberry Pi 4.

Python-based software implementation.

Tested in real-world walking environments.
